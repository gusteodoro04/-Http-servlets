Explorando o protocolo HTTP com Java Servlets

Tecnologias de Desenvolvimento para Internet III – Fundamentos do HTTP. Cada seção abaixo chama um dos 5 servlets.

Servlet 1 – Cabeçalhos da requisição (GET /headers)

Mostra o User-Agent, o Referer, o idioma, as codificações aceitas, o IP, a versão do HTTP e todos os outros cabeçalhos.

Abrir /headers

Servlet 2 – Corpo da requisição (POST /request-body)

O formulário envia os campos por POST e o servlet mostra o corpo da requisição como chegou.

Servlet 3 – Sessão e cookies (GET /session)

Na primeira visita o servidor grava um cookie com o seu usuário; nas visitas seguintes ele diz “Bem-vindo de volta”. Abra o link duas vezes.

Abrir /session · Apagar cookie e sessão

Servlet 4 – Status HTTP (GET /status?code=...)

O código de status da resposta vem do parâmetro code da URL. Abra a aba Rede (F12) para ver o status de cada uma:

200 · 201 · 204 · 301 · 302 · 400 · 401 · 403 · 404 · 405 · 418 · 500 · 503 · lista completa

Servlet 5 – Métodos suportados (OPTIONS /methods)

O navegador só envia OPTIONS por script, então o botão abaixo usa fetch com method: 'OPTIONS'.

Abrir /methods (GET)
